## 🚀 Running Locally

1. Clone or download the repository:
   ```bash
   git clone <repo-url>
   cd "Vaibhav port"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build production static bundle:
   ```bash
   npm run build
   npm run start
   ```
